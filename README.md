# Webora Tec Frontend Internship — Task 1

## Personal Portfolio Website

A responsive personal portfolio created with HTML and CSS, with a small JavaScript enhancement for the mobile navigation and demo contact form.

### Sections
- Home
- About Me
- Skills
- Projects / Practice
- Contact

### Current skills shown
- C++ (Basic)
- C (Basic)
- HTML (Basic)
- Domestic Data Entry Operator

### Run locally
Download or clone this repository and open `index.html` in a browser.

### Before final submission
1. Add your profile photo (see note below).
2. Add your GitHub profile URL in the Contact section.
3. Open the site on a phone and a computer and check all navigation links.
4. Capture a full-page screenshot and save it in `screenshots/portfolio-preview.png`.
5. Commit and push all final files to this public repository.

### Profile photo
`photo.jpg` is used in the circular profile image. Keep it in the same folder as `index.html` and `style.css`.

### Contact form
The form is a front-end demonstration only. It does not send or store messages. A backend or form service is required for real submissions.
